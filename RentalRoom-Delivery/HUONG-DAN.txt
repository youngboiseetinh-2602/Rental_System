HUONG DAN CHAY RENTAL ROOM SYSTEM

Yeu cau:
- Da cai va mo Docker Desktop
- Co ket noi Internet de tai MySQL lan dau

1. Mo CMD tai thu muc nay.

2. Import Docker images:
docker load -i rental-room-backend-1.0.tar
docker load -i rental-room-frontend-1.0.tar

3. Tao file .env:
copy .env.delivery.example .env

4. Mo .env va dien:
- DB_PASSWORD
- IMAGEKIT_URL_ENDPOINT
- IMAGEKIT_PUBLIC_KEY
- IMAGEKIT_PRIVATE_KEY

5. Khoi dong:
docker compose --env-file .env -f docker-compose.delivery.yml up -d

6. Kiem tra:
docker compose -f docker-compose.delivery.yml ps

7. Truy cap:
Frontend: http://localhost:3000
Backend health: http://localhost:8080/api/public/health

8. Dung chuong trinh:
docker compose -f docker-compose.delivery.yml down

Luu y:
- Khong chia se file .env.
- Database mau chi tu dong import trong lan khoi tao dau tien.
